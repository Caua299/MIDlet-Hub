## MIDlet Hub 1.0.0

Primeira versão oficial do MIDlet Hub, um fork não oficial do [J2ME Loader](https://github.com/nikita36078/J2ME-Loader) com interface modernizada.

### Novidades
- Interface em Material 3, com cores dinâmicas (Material You) no Android 12+ e modo AMOLED
- Biblioteca de jogos com cartões e ícones maiores, abas Todos / Favoritos / Recentes
- Painel de detalhes do jogo (ícone, autor, versão, última vez jogado)
- Pontos de save: guarde cópias do progresso salvo de cada jogo e restaure quando quiser
- Configurações reorganizadas em grupos, com ícones na cor do tema
- Tela de configuração por jogo com novo visual
- Nova paleta padrão para os controles virtuais (vale para perfis novos)
- Novo ícone do app
- Relatórios de erro salvos localmente, sem envio para nenhum servidor

### Instalação
Baixe o arquivo `MIDlet_Hub-1.0.0.apk` abaixo e instale. O app tem um ID próprio e convive com o J2ME Loader original.

### Créditos
Baseado no J2ME Loader de Nikita Shakarun, licenciado sob Apache 2.0.

## MIDlet Hub 1.0.0 (English)

First official release of MIDlet Hub, an unofficial fork of [J2ME Loader](https://github.com/nikita36078/J2ME-Loader) with a modernized interface.

- Material 3 interface with dynamic colors (Material You) and an AMOLED mode
- Game library with cards and larger icons, with All / Favorites / Recent tabs
- Game details sheet (icon, author, version, last played)
- Save points: keep copies of each game’s saved progress and restore them any time
- Settings reorganized into groups, with theme-colored icons
- Per-game configuration screen with a new look
- New default palette for the virtual controls (new profiles)
- New app icon
- Crash reports saved locally, nothing is sent to any server

Download `MIDlet_Hub-1.0.0.apk` below and install it. The app has its own ID and installs alongside the original J2ME Loader.
